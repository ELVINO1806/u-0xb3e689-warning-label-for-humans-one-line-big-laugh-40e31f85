## The entry

> WARNING: This human's mouth starts moving three seconds before the brain finishes loading.

One funny single-line safety warning label that should come printed on every human being — 90 characters, well inside the 160-character limit.

## How it works

`main.py` writes the entry line to `/output/entry.txt`. It is fully deterministic: no clock, no randomness, standard library only.

```sh
python3 main.py
```

## Why this line

The joke lands on the last few words: the mouth is already talking while the brain is still booting up. It is true about people in general, it sounds like a real printed warning label, and it needs no setup — one read, one laugh.
